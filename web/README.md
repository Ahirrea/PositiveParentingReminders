# positive-parenting-web — Design-Prototyp, nicht ausgeliefert

Dieses Next.js-Projekt ist ein **Wegwerf-Prototyp** zum schnellen Ausprobieren
von Layouts für den Onboarding-Flow. Es ist **nicht das Produkt** und wird bei
Änderungen an der Android-App **nicht mitgepflegt** — die beiden
Implementierungen teilen keinen Code und dürfen auseinanderdriften.

Das Produkt ist die native Android-App unter `app/`. Entschieden in
[ADR-003](../docs/entscheidungen/ADR-003-zwei-plattformen.md).

## Lokal starten (falls doch mal gebraucht)

```bash
cd web
npm install
npm run dev
```
